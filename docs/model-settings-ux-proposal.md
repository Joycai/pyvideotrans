# 模型配置 UX/UI 优化方案

状态：已实现，等待用户验收。依据：2026-10-30 用户截图、model_list_editor.dart、provider_section.dart 与设计系统。

## 问题与目标

列表同时展示完整 ID、接入方式、报文族、能力与悬停操作；长 ID 让标签换行，行高和扫描路径不稳定。展开箭头与参数按钮重复，设为默认使用向上箭头，删除使用关闭图标，动作含义不明确。常驻添加表单要求用户理解协议与模型族，常用模型又以长按钮重复占据空间。

目标：已有模型易比较；添加内置模型无需配置协议；默认模型有明确动作；参数和接入细节按需出现。沿用现有设置即时保存、主题与紧凑桌面控件。

## 信息架构

模型分区独占设置内容宽度，标题与说明置顶，不占左侧宽标签列。头部右侧只有「添加模型」。

列表每行分层：主行显示预置友好名称、默认标记、常驻「配置」和更多菜单；第二行显示可复制的完整模型 ID；第三行用低强调文本显示处理方式和经声明确认的能力。自定义模型无友好名称时显示其真实 ID，不生成误导性名称。

示例名称：Qwen Audio 3.1 · 整文件转写、Qwen Audio 3.1 · 流式文件转写。保留「文件」避免误以为支持麦克风实时识别。友好名称只作 UI 元数据，请求仍使用原始 ID。

默认标记唯一且常驻。更多菜单提供「设为默认」「复制模型 ID」「移除模型」；设为默认沿用内部置顶语义，完成后保留焦点并提供反馈。移除只影响候选列表；删除默认模型前说明接替者，删除最后一项前明确说明现有恢复预置列表行为，不能显示成真正空列表。

## 添加模型

打开对话框，默认显示「内置模型」，另有「自定义模型」。内置列表支持按名称 / ID 搜索，展示友好名称、ID、处理方式及能力；已添加模型标明状态且不可重复提交。选择后确认添加，使用完整预置 ModelSpec，不让用户再选协议。不将“内置”宣传为已实测或推荐。

自定义表单首先输入模型 ID；接入方式和报文族位于明确标注的高级接入区。已知预置自动匹配；未知 ID 的推断仅用于预填并提示用户核对。提交前确保必需声明明确且组合合法，错误显示在字段旁并保留输入。运行时仍按显式声明路由。

## 配置与识别增强

点击「配置」在当前行下展开一个详情区域，同一时刻展开一项，取消重复箭头入口。
依次展示：模型默认参数、只读能力说明、折叠的接入信息。没有参数时显示说明，不制造空表单。

能力文案区分「上下文提示」「即时热词」「说话人分离」；仅按真实接入能力展示，不把“支持提示词”直接当作“支持独立词表报文”。支持是能力，启用状态由当前任务参数决定。

模型设置管理能力和默认参数；上下文内容和词表选择继续在新建任务页编辑，可提供「前往新建转写」入口。任务页将两者归入「识别增强」，显示上下文计数、已选词表与有效词条数；限制与后端校验复用，超限明确说明，不静默截断。任务入队后修改设置不影响已有任务。

## 视觉与交互

沿用 AppSpacing、AppTextStyles、ContentPanel、现有按钮及 GlassDialog。默认状态使用轻量蓝色标记；能力使用次要文本，不堆叠描边胶囊。完整 ID 可选择 / 复制，窄宽时换行，避免仅靠 tooltip 获取关键信息。

以模型分区可用宽度决定布局：窄宽时名称、动作、ID 与能力上下排列。配置按钮和更多菜单始终可见；Tab 可访问所有操作，Enter 激活，Esc 关闭弹窗并将焦点还给触发按钮；添加/移除后焦点落到合理位置。浅深色复用现有主题，不新增装饰性渐变。
