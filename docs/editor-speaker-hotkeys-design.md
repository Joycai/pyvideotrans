# 说话人快捷分配

## 目标与范围

编辑字幕时无需反复打开右侧说话人菜单。字幕表上方提供可见的字母键与目标映射，支持单选、可见多选和不连续选区；每次分配可一步撤销、重做。

## 实施计划

1. 为任务与本地编辑会话增加独立映射存档，兼容旧 JSON。
2. 控制器按身份编号分配，防止失效编号复用；保持字幕保存和撤销规则。
3. 增加快捷分配栏、可配置字母键和可搜索目标选择器。
4. 验证持久化、选区、撤销、只读、焦点与主题；只读审查后提交 PR。

## 行为契约

- 空配置显示操作说明；配置首次提供 A/B/C/D 空槽，未选目标的槽不保存。
- 字母键可选 A–Z，J/K 保留给上下条；已占用的键禁用并解释原因。
- 目标是当前文档的说话人身份，或者“清除说话人”；显示名称与编号区分同名身份。
- 仅字幕表焦点范围响应，不影响输入框、菜单或输入法组字；不重复连发、不自动跳行。
- 目标重命名时跟随名称；目标消失时保留失效提示，不自动重绑。流水线更换文档时旧身份映射失效。
- 配置存储于任务 JSON 或本地编辑状态，不进入字幕内容或文档撤销栈，不增加未写入修改数。
- 配置对话框取消不保存；应用后回到字幕表焦点。分配后用轻量提示显示实际修改条数。

## 布局和主题

字幕表工具栏下新增一行，左侧标题、中间可横向滚动的映射按钮、右侧选中条数与配置入口。
长名字省略并显示完整 tooltip；浅深色均复用主题令牌。
浮层使用 GlassPanel，按钮使用 ControlButton / QuietButton / PrimaryButton，键位菜单使用 AppDropdown，搜索使用 SingleLineField。
