# 编辑器：选区内整理说话人

状态：已实现，验证记录见文末。

## 问题与现状

不同片段中的同一识别编号不一定代表同一个人。当前 `SpeakerManager` 调用全局
`renameSpeaker` / `mergeSpeaker`，无法隔离片段。编辑器已有 Shift 连选、主修饰键
加选，以及对选中字幕统一指派 / 新建说话人的能力；缺少按选区中的原说话人分别处理。
设计依据为当前控制器、检视面板和 `editor_multi_select_light.png` 本地基线。

## 入口与范围

- 检视面板新增明确的「整理选区说话人…」按钮，紧邻已有说话人指派字段。单选也可用。
- 现有全局入口标成「管理全部说话人…」，打开后标题为「全部说话人」，避免作用域混淆。
- 沿用 Shift+点击 / Shift+方向键选连续字幕，Cmd/Ctrl+点击选择不连续字幕。
- 对话框作用域固定为打开时的选中字幕，不在弹窗中提供切换到全局的开关。
- 显示完整条数、行号范围摘要、首尾时间。非连续选择明确标明「非连续选区」。
- 筛选开启时明确提示「仅处理选中的可见字幕，不包含被筛选隐藏的字幕」。首尾时间只是
  位置提示，不代表覆盖其中全部字幕。首期不引入时间输入或自动推断媒体片段边界。

## 对话框

建议宽度 720 logical px，上限为窗口可用宽度减两侧边距。固定范围说明和底部操作区，
中部列表独立滚动；窄窗口把每条映射改为上下两行。

```text
整理选区说话人
已选 80 条 · 第 121–200 条 · 00:12:30–00:18:45
修改仅应用到这些字幕

原说话人                 处理方式 / 目标
说话人 1 · 32 条          [保持不变                  ▾]
说话人 2 · 28 条          [命名为新说话人            ▾]
                         [李老师                     ]
说话人 3 · 20 条          [替换为已有说话人          ▾]
                         [王老师 · 编号 5           ▾]

将修改 48 条字幕，新增 1 位说话人
                                  [取消] [应用到 48 条字幕]
```

每个来源行包含徽标、名字、编号、选区内条数。未分配的字幕汇总为「无说话人」。
处理方式为「保持不变」「命名为新说话人」「替换为已有说话人」「清除说话人」。
目标下拉可搜索，列出全文已有身份，显示编号避免重名混淆。

多选来源行后显示「合并为…」操作，可选择已有身份或输入一个新名字；被选来源显示
共同目标。批量合并与单行替换最终都表现为同一份映射预览，合并本身不立即修改文档。
新增目标可被其他来源行选择，取消该新目标时必须清除引用并提示重新选择。

## 三种核心操作

| 操作 | 例子 | 应用结果 |
| --- | --- | --- |
| 命名 | 本选区的说话人 2 → 李老师 | 新建独立身份，将选区中原为 2 的字幕指派给它；选区外编号 2 及名称不变 |
| 替换 | 本选区的说话人 2 → 已有王老师 | 只迁移选区内原为 2 的字幕，王老师在其他位置的字幕保持不变 |
| 合并 | 本选区的说话人 2、3 → 李老师 | 两个来源映射到一个新建或已有身份；其他来源和选区外字幕不变 |

局部命名始终创建新身份，即使该来源当前只出现在选区内，保持明确且一致的语义。
新名字与已有身份同名时提示「已有同名说话人，可改用替换」，不按名字自动合并。
空白名字不能应用。清除只解除选区内关联，不删除全局名单项。
已有的导出标签开关仍是全文设置，不放入局部弹窗。

## 事务与数据契约

- 弹窗内为草稿，取消 / Esc 不改变文档；有草稿时关闭丢弃本次草稿，不增加确认层。
- 应用时基于原始身份同时执行所有映射，A→B、B→C 不连锁成 A→C，交换 A/B 也成立。
- 一次应用为一个撤销步骤，撤销恢复字幕关联与新增身份；重做恢复相同结果。
- 复用现有字幕 speaker ID 和全局名字表，局部命名通过新 ID 实现，不引入按时间变化的名字。
- 不删除来源身份，不更改文本、时间轴、译文、校对标记或全局筛选条件。
- 弹窗打开时记录文档及目标集合；应用前验证文档未变化且会话仍可编辑。变化时阻止提交，
  提示「字幕已发生变化，请关闭后重新选择」，不能按已失效的下标继续写入。
- 通过现有提交 / 历史路径保存编辑进度，字幕文件仍需保存动作写入。
- 应用后遵循当前筛选；若改动导致字幕退出筛选结果，反馈说明，并提供「清除筛选」动作。

## 状态、风格与无障碍

- 无选区时禁用入口，说明「先选择字幕」；运行中的只读会话禁用，说明等待任务结束。
- 没有实际变化时应用按钮禁用，显示「请选择处理方式」。只统计真正变更的字幕条数。
- 沿用 GlassPanel / 现有按钮与字段、蓝色主动作、说话人徽标色、浅深主题令牌。
- 长姓名允许摘要省略及完整 tooltip；范围详情可展开，不能只靠颜色说明合并关系。
- Tab 顺序为来源选择、处理方式、目标字段、底部动作。Esc 先关下拉再关对话框。
  输入框中的数字不触发编辑器指派快捷键；输入法组字时 Enter 不提交。

## 实施记录

- 选区整理采用来源行 +「命名 / 替换…」目标选择器，目标选择器提供新名字、可搜索的已有
  身份和清除；来源复选框 +「合并为…」复用同一目标选择器，减少每行展开字段的拥挤。
- 新建身份可被其他来源复用。重置来源只解除草稿映射；未被使用的新身份不会写入文档。
- 复用现有选区与保存路径，新增纯映射规则、原文档校验、原子提交，以及编辑器重做栈。
  重做快捷键为主修饰键 + Shift + Z，输入框内让给文本编辑。
- 新增局部弹窗浅深色截图测试；基线生成被自动审批阻止，因此未更新任何 golden 基线。

### 主题控件复核

目标选择弹窗统一使用 Dialog + GlassPanel、LabeledField + SingleLineField、PrimaryButton /
ControlButton / QuietButton 与 InlineNote；两个弹窗的圆角、阴影和间距采用项目令牌。
复选框及双行列表项保留 Material 控件，继承应用的 ColorScheme、TextTheme 和 compact
密度，列表标题与说明显式取项目文字样式。没有为本功能另建配色或 ThemeData。
