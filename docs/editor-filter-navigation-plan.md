# 编辑器过滤后的导航与选区

目标：说话人过滤后 J/K 从当前字幕附近继续；分配说话人导致当前行隐藏时接续可见行。

实施与验证：
- J/K 对隐藏行按文档位置和方向寻找相邻可见行；方向无结果时停留。
- 说话人修改提交时，焦点退出筛选则优先后继、其次前驱；仍可见时保留多选。
- 可操作选区只包含可见行；结果为空时检视面板无当前字幕，禁止单条编辑。
- 可见列表变化时重新检查当前行是否需要滚入视野，保留原有键盘焦点范围。
- 补充控制器与真实快捷键回归测试，运行 analyze、全量测试与 golden，再做只读审查。

不改变字幕保存、撤销文档快照和播放跟随规则。手动筛选仍保留原文档定位，解除筛选后可恢复原选区；修改说话人引起的自动接续会替换为单选。
